# アプリ操作ガイドの撮影手順

`/manual/app-guide`(`src/app/manual/app-guide/page.tsx`)の画像(`public/manual/app-guide/*.png`)を撮り直すための手順。アプリのUIが変わったら、この手順でClaudeに撮り直させる。

- 撮影端末: Androidエミュレーター(AVD `medium_phone`)、ライトモードのみ。iOSは同じUI(Compose Multiplatform)なので撮らない
- 接続先: 本番(`https://resp.work`)
- 操作の基本(エミュレーターの起動、`android layout`、補助スクリプト)は `resp/.claude/skills/emulator-verify/SKILL.md` に従う

## 説明用データ(2026-09-29作成)

| 項目 | 内容 |
|---|---|
| トピック | 「朝型と夜型、勉強がはかどるのはどっち?」(ルートのresp id `818`) |
| 見る人(撮影時のログイン) | `testA`(オレンジの「A」アイコン) |
| 話し相手 | `testB`(青の「B」アイコン)、`test02` |
| 認証情報 | `~/.config/resp/test_account_testA.properties` / `test_account_testB.properties` / `test_account.properties`(test02)。中身は表示・コミットしない |

ツリーの構成(括弧内は投稿者、→はリクエスト先):

```
818 トピック(運営)
├─ 819 朝型派です…(testB → testA)
│   ├─ 820 わかります…(testA → testB)
│   │   └─ 821 前の晩に…(testB)  ← testAが投げ銭・ピン済み
│   └─ 822 朝は出かける前で…(test02)
├─ 825 時間帯よりも…(testA)
│   └─ 826 同感です…(testB → testA)  ← testAがうなずき済み
├─ 823 夜型派です…(test02 → testA)  ← 未応答のまま残す(「リクエストされています」の撮影用)
└─ 828 朝型が正しいことは…(testB → testA)  ← testAが懐疑済み
```

日本語は `adb shell input text` で入力できない(ホストとのクリップボード共有も効かなかった)。そのため、データはAPI(`jwt_login/` でトークンを取得し、`api/topic_add/`・`api/post_response/` に投稿)で作った。入力画面はプレースホルダーのまま撮る。

うなずき・投げ銭・ピンは一度しかできないので、撮り直すときは新しいリクエストを作るか、別のトピックを作り直す。

## 撮影のしかた

ステータスバーをデモモードにして、時刻とアイコンを固定する:

```bash
ADB=~/Library/Android/sdk/platform-tools/adb
$ADB shell settings put global sysui_demo_allowed 1
$ADB shell am broadcast -a com.android.systemui.demo -e command enter
$ADB shell am broadcast -a com.android.systemui.demo -e command clock -e hhmm 1000
$ADB shell am broadcast -a com.android.systemui.demo -e command notifications -e visible false
```

撮影と縮小(長辺900px。ページ側は405x900を前提にしている):

```bash
android screen capture -o shot.png && sips -Z 900 shot.png
```

`06-02.png`(リクエスト先の選択シート)は、背景に仮入力の文字が写るため、シート部分(y=465から高さ435px)だけを切り出している。この環境の `sips` では切り出しが効かなかったので、CoreGraphics(`CGImage.cropping`)を使うSwiftスクリプトで切り出した。

## 撮影時に見つかったアプリの不具合(2026-09-29時点)

- **タイムラインが最初は空になる**: タイムラインのタブを開いても `TimeLineViewModel.load` が呼ばれず、「投稿はありません」と表示される。空の状態では引っ張って更新しても読み込まれない。フィルターを選び直すと表示される
- **「送信済み・すべて」が空になることがある**: `RequestByMeScreen` が初回表示のときに `load()`(既定は未返信)と `changeFilter(ALL)` を同時に呼ぶ。後から返ってきた「未返信」の空の結果が上書きしていると考えられる
- **トピック統計の「投げ銭合計」が0のまま**: 投げ銭を1回したあとも0と表示された(未調査)
